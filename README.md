# GridScope Studio

A lightweight energy analysis studio for turning household billing or meter CSVs into clean metrics, charts, tables, and short observations.

The main report opens in a browser and lets people upload their own CSV locally. The reproducible pipeline underneath still uses R, SQLite, and reusable SQL query files, so the same analysis can be rerun from the command line.

## Quick Start

Generate the demo portfolio report:

```sh
Rscript R/run_analysis.R
open output/report.html
```

Analyse your own CSV:

```sh
Rscript R/run_analysis.R --input data/sample_energy_upload.csv --output output/custom-report.html
open output/custom-report.html
```

## CSV Columns

Required:

- `day` or `date`
- either `grid_import_kwh` or `total_kwh`, or the tiered fields `peak_kwh`, `shoulder_kwh`, and `offpeak_kwh`

Optional:

- `household_id`
- `neighbourhood` or `suburb`
- `solar_export_kwh`
- `estimated_bill`

The browser upload flow accepts the same columns and produces graphs immediately in the page.

## Requirements

- R 4.x
- SQLite CLI: `sqlite3`

On macOS, SQLite is usually already available. Check with:

```sh
sqlite3 --version
```

## Outputs

- `output/report.html`: browser report with CSV upload tools and demo analysis
- `output/custom-report.html`: generated when an input CSV is supplied
- `output/tables/`: CSV summaries from the SQL queries
- `output/figures/`: PNG charts generated by R

## Analysis Included

- Monthly grid import and solar export trends
- Load mix across peak, shoulder, off-peak, and solar export
- Group comparison by neighbourhood or suburb
- Cost rollups when a bill or cost column is supplied
- Data quality summary with record, day, and household counts
